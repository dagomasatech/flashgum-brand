# Flash gum — Brand assets

Repositorio oficial de identidad visual de Flash gum.

## Principios de marca

Simple. Directo. Con energía.

La identidad visual se basa en:

- Blanco
- Negro
- Rosa Flash gum
- Formas simples
- Bordes rectos
- Mucho espacio en blanco
- Uso contenido de recursos gráficos

## Assets

Los recursos oficiales están disponibles en `/assets`.

### Logo principal

`assets/01-logo-horizontal.png`

Usar como versión principal de la marca.

### Logo inverso

`assets/02-logo-inverse.png`

Usar únicamente sobre fondos oscuros.

### Símbolo

`assets/03-symbol.svg`

Usar cuando no exista espacio suficiente para el logotipo completo.

### Recursos gráficos

`07-bolt-accent.svg` y `08-ui-accent.svg` son recursos secundarios.

No utilizar de manera repetitiva.
