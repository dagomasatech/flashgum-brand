# Flash gum UI Guidelines

## Concepto

La interfaz debe transmitir:

Simple. Directa. Con energía.

## Regla principal

Una UI Flash gum debe ser principalmente:

BLANCO + NEGRO + PEQUEÑOS ACENTOS ROSAS

No convertir toda la aplicación en rosa.

## Formas

Cards: rectangulares
Inputs: rectangulares
Buttons: rectangulares

Border radius:

0px - 4px

Evitar interfaces excesivamente redondeadas.

## Uso del rosa

Usar para:

- acción principal
- estado activo
- selección
- focus
- pequeños elementos de marca

No utilizar como fondo predominante.

## Recursos gráficos

El círculo y el rayo pertenecen al universo de marca.

No convertirlos en elementos decorativos repetitivos.

## Principio de decisión

Si existe duda entre añadir algo o eliminarlo:

eliminarlo.

Si existe duda entre decoración y espacio en blanco:

espacio en blanco.

Si existe duda entre redondeado y recto:

recto.
