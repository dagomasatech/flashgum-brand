# FLASHGUM_UI_GUIDELINES

## Principio

**Simple. Directa. Con energia.**

La UI debe apoyarse en espacio en blanco, tipografia clara, bordes casi rectos y golpes controlados de rosa.

## Tokens

- Rosa principal: `#D95885`
- Rosa claro: `#FF8EC4`
- Negro: `#0A0A0A`
- Blanco: `#FFFFFF`
- Fondo suave: `#F7F4F5`
- Borde: `#EAE7E8`
- Texto secundario: `#6F6A6C`

## Formas

Cards, inputs, botones, modales y tablas: `border-radius: 0-4px`.
Evitar pills salvo chips/tags/estados.

## Logo

- Cabecera amplia: `logo-horizontal.png`.
- Fondo oscuro: `logo-horizontal-inverse.png`.
- Espacio reducido: `symbol-primary.svg`.
- No deformar, rotar, sombrear ni recolorear arbitrariamente.

## Uso del rosa

Usar para acciones primarias, foco, seleccion y detalles de marca. Evitar pantallas completas rosas salvo splash/campanas muy puntuales.

## Elementos decorativos

`ui-accent-corner-light.svg` y `pattern-bolts-light.svg` son opcionales. No usar ambos de manera constante en todas las pantallas.
